# DEF-0002 — Epaper connectors missing after Infini restart (USB still plugged)

Closed 2026-08-16 (human): connection stable; restSpine/restShape parse + hello document.

## Reproduce

1. USB plugged. Document has nodes + connectors.
2. Kill Infini, start Infini.
3. Infini: RM connected, nodes + connectors painted.
4. Epaper: nodes painted, connectors not. Drag still warps on Infini.

## Cause

Infini `doc_load` / `toJSON` stores connector rest as `restSpine`. Epaper `nodeFromJson` only read nested `restShape`. Warp spine length &lt; 2 → `drawWarpedConnector` no-ops. Data and Infini math were fine.

## Fix

Parse both `restShape` and `restSpine`. Hello with `queued=0` carries the device document so Infini hydrates before echoing `doc_load`. Empty Infini `doc_load` does not wipe a non-empty device tree.
