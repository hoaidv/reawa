# DEF-0003 — Lid close/open: documents reset, then Infini waits disconnected

Closed 2026-08-16 (human): connection stable. Keepalives, powerMonitor socket drop, empty doc_load guard.

## Reproduce

1. USB plugged, Infini running, documents live.
2. Close laptop lid, open lid.
3. Infini briefly shows RM connected; both canvases empty; ink does not sync.
4. Then Infini: RM disconnected — waiting.

## Cause

Mac sleep leaves StrokeSync TCP half-open (`ConnectedState` so the 2s retry never runs). Renderer remount can emit an empty `doc_load`. Device keepalive used OS defaults (hours).

## Fix

- `powerMonitor` suspend/resume destroys RM sockets so epaper retries.
- Linux TCP_KEEPIDLE 5s / INTVL 2s / CNT 4; Infini `setKeepAlive(true, 5000)`.
- Hello document + ignore empty `doc_load` when the device still has a tree (DEF-0002).
