# DEF-0001 — USB gadget not enumerated; ifconfig restore does not restore ping

## Story

[STORY-EP-036](../stories/STORY-EP-036.md) **done**. Human 2026-08-16: connection stable. Closed with UsbLink infra (worker) + 5s TCP retry.

## Field note (2026-08-16 after ICMP + g_ether)

Human lid test: `10.11.99.1` still unreachable from Mac. Drawing laggy/frozen. Then **cannot SSH until tablet restart**.

Cause of freeze/brick: `probe()` ran `ping -W 1` and `restoreWithoutUnplug()` ran `usleep` + **`modprobe -r g_ether` on the UI thread**. Unloading g_ether can leave the gadget dead until reboot. Forbidden.

## Safe retry

- No ICMP on the ink thread.
- No `g_ether` unload.
- UDC configfs/platform cycle on a **worker thread** only.
- `:9877` ConnectionRefused → do not bounce (EP-034).
- Path timeout/unreachable → bounce after two failures.

If Mac ping still fails after UDC cycle, log that unplug may still be required — do not brick USB.

## Story

[STORY-EP-036](../stories/STORY-EP-036.md) **FAIL**. Human 2026-08-16: USB cable still plugged, **ping `10.11.99.1` times out**. Same class as xochitl Help omitting `10.11.99.1`.

## Expected

Gadget-down restore brings `10.11.99.1` back without unplug, then SSH/StrokeSync can retry (AC2/AC3).

## Actual

Current restore (`usb0` UP + assign `10.11.99.1` + autosuspend off) does **not** restore ping. SSH keepalives (EP-034) cannot help: there is no L2/L3 path.

## Diagnosis (human)

Must **establish the USB hardware/gadget connection first** (UDC / g_ether / configfs bind so the Mac NIC appears), **then** re-activate SSH over USB. Ifconfig-on-usb0 is too late if the gadget is not enumerated.

## Field note (2026-08-16 lid #2)

Human: first lid reconnects; **second** lid → Mac `ping 10.11.99.1` timeout, Infini empty, epaper keeps ink, Quit Infini does not help.

Tablet `usb0` can still show `10.11.99.1` UP while the **Mac** NIC is dead. Classify must use **carrier + ping `RM_SYNC_HOST`**, not local addr alone, or restore never runs.

## Reproduce

1. Leave USB plugged.
2. Wait until `ping 10.11.99.1` times out (Mac).
3. Observe epaper still running; Infini/SSH dead.
4. Unplug-plug restores `10.11.99.1` (control). Software restore does not.

## Asks for `/dev`

Do not treat SSH/TCP keepalive as this class. Sequence: (1) re-bind/reset USB gadget so the host sees ethernet, (2) confirm `10.11.99.1`, (3) then StrokeSync 2s retry. If gadget re-bind is impossible from userspace, log that — do not claim unplug is required until that log.
