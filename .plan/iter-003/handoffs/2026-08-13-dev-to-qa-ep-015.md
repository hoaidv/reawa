## Behaviour (host)

1. Structural `commitOp`: if depth==20 drop oldest; push `{ snapshot, opId, kind }` of the **current** tree; apply; enqueue one `doc_change` for that op.
2. `undo`: if gesture in flight, latch and run after commit; empty ring is a no-op; else pop newest, restore tree, enqueue `doc_change { op: restore_snapshot { document } }`.
3. Viewport pan / tool / selection update UI fields only — ring unchanged.
4. Intermediate manipulation frames (`previewManipulationFrame`) do not push; one `commitOp` at release → depth +1.
5. `onAcceptedDocLoad` empties the ring (optional tree replace). No handshake.
6. Op name is **`restore_snapshot`** only.

Rejected ops leave tree, ring, and queue unchanged. Raw `applyOp` does not push.
